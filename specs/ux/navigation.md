# Navigation

## Workspace

- Startup opens the latest workspace or falls back to **My Notes**. Use **Open workspace…** or recent workspaces to switch.
- The header shows the workspace name or active note path. The tree opens notes and focuses folders.

## Notes

- Tree items, tabs, and workspace links navigate to notes; folder links focus the folder.
- Closing the active tab selects the most recent remaining tab. Closing the last shows the empty-note prompt.
- `⌘K` / `Ctrl+K` focuses title/path search; Enter opens the first result and Escape closes it. Header controls toggle theme and Markdown source view.

## Saving

- Switching notes/workspaces and closing the active tab attempts to save first. A failed save prevents the switch and shows an error.
- External-change prompts let users load the disk version or keep their draft.

## Gaps

- Search has no folder results or commands. Tab and tree keyboard navigation shortcuts are absent.
