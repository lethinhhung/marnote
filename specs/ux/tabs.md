# Note tabs

- Show open notes in a tab bar. Selecting a tab opens that note; highlight the active tab.
- Show each note's filename, optional emoji icon, unsaved-change indicator, and close button.
- Apply the save safeguards in [Saving](saving.md) before switching or closing the active tab.
- Closing the active tab selects the most recently opened remaining tab. Closing the last tab shows the empty-note view.
- The **+** button creates a note in the current note's parent folder.
- Restore open tabs and drafts after restart, as specified in [Saving](saving.md). Allow tabs to be reordered.
- Right-click a tab for **Close**, **Close others**, and **Close all**. Apply normal save safeguards to each action.
- Keep the tab bar within the window; scroll horizontally when tabs overflow.
- Scroll overflowing tabs with a mouse wheel as well as touchpad gestures.
- Show left/right chevrons when tabs are hidden; clicking a chevron scrolls the bar.
- Keep **+** at the end of the tab sequence so it scrolls with the tabs.
