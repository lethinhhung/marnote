# Note tabs

- Show open notes in a tab bar. Selecting a tab opens that note; highlight the active tab.
- Show each note's filename, optional emoji icon, unsaved-change indicator, and close button.
- Save the current draft before switching or closing. If saving fails, keep the tab open and prevent navigation.
- Closing the active tab selects the most recently opened remaining tab. Closing the last tab shows the empty-note view.
- The **+** button creates a note in the current note's parent folder.
- Restore open tabs and drafts after restart. Allow tabs to be reordered.
- Right-click a tab for **Close**, **Close others**, and **Close all**. Apply normal save safeguards to each action.
- Adapt the tab bar to the window width; allow horizontal scrolling when tabs do not fit.
