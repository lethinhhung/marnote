# Note tabs

- Open notes appear in a tab bar. Selecting a tab switches to that note; the active tab is highlighted.
- Tabs show the note filename, optional emoji icon, and an unsaved-change indicator. Close a tab with its **×** button.
- Closing the active tab saves first, then selects the most recently opened remaining tab. Closing the last tab returns to the empty-note view.
- Switching tabs saves the current draft. A failed save prevents the switch.
- **+** starts a new note in the current note's parent folder.
- Tabs and drafts are kept for the current app session; they are not restored after restart. Tabs cannot be reordered.
