# Memory

Durable knowledge for the current Strata run. Memory is subordinate to `specs/`, `AGENTS.md`, and the epic; it records decisions, progress, and caveats, not new requirements.

## Files

- `decisions.md` — durable architectural and workflow decisions.
- `progress.md` — per-stage status for the active epic.
- `notes.md` — implementation notes, evidence, and unresolved items.

Update these in place; do not duplicate entries.
